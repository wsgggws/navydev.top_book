# Lector 界面规格 v1

> 规范性文档。实现与本文件不一致时，以本文件为准并同步修改实现。
> 配套：[API 契约](API.md)、[主构建提示词](../PROMPT.md)、[仓库指令](../AGENTS.md)
> 覆盖两端：**网页端**（§1–§7）与**终端端**（§8–§10）。

## 0. 设计立场

**位置只有一种表示。** 界面层的"当前位置"就是 API 契约里的 `Cursor = {book_id, chapter_id, sentence_id, word_index}`。阅读游标、听书高亮、终端跟随、进度读写、短码分享，都是这一个游标的投影。界面不得引入第二套位置概念（例如"页码"或"段落序号"）作为内部状态。

阅读器的界面只有一个职责：**让人忘记界面在。**

因此：

- 正文区永远是视觉主体，控件在需要时出现、不需要时退场。
- 所有装饰（边框、阴影、分隔线）保持极低对比，不与正文争抢注意力。
- 动效只用来解释"发生了什么"（位置跳转、内容切换），不做纯装饰动画。
- 三套主题共用同一套间距与字号比例，只换色板。

**特色落在两处**，其余一律克制：

1. **游标线** —— 当前句左侧一道 2px 琥珀色竖线 + 极淡背景。它是全书唯一的"高饱和"元素。
2. **逐词高亮** —— 听书时正在朗读的词逐个点亮，朗读完的字保持"已读"的低对比底色。

## 1. 设计 token

CSS 自定义属性，定义在 `web/styles/tokens.css`。三套主题只覆盖色板，**不动**间距、字号、行高。

### 1.1 色板

| token | 纸白 paper | 羊皮 sepia | 夜间 night | 用途 |
| --- | --- | --- | --- | --- |
| `--bg` | `#faf9f6` | `#f4ecd8` | `#16181c` | 页面底 |
| `--surface` | `#ffffff` | `#faf3e0` | `#1e2126` | 卡片、抽屉 |
| `--text` | `#23201c` | `#3a3226` | `#d8d5cf` | 正文 |
| `--text-dim` | `#6b655c` | `#7a6f5c` | `#8b8781` | 次要信息 |
| `--text-faint` | `#a49d92` | `#a89c86` | `#5f5c58` | 禁用、占位 |
| `--border` | `#e6e2da` | `#e0d4b4` | `#2a2e34` | 分隔线 |
| `--accent` | `#c8791f` | `#b06a12` | `#e0a054` | 游标线、强调 |
| `--accent-soft` | `rgba(200,121,31,.10)` | `rgba(176,106,18,.12)` | `rgba(224,160,84,.14)` | 当前句背景 |
| `--spoken` | `#f2e3cc` | `#ecdcbb` | `#33302b` | 已朗读过的词底色 |
| `--highlight` | `rgba(200,121,31,.28)` | `rgba(176,106,18,.30)` | `rgba(224,160,84,.32)` | 当前词 |

**对比度底线**：正文 `--text` 对 `--bg` ≥ 7:1；`--text-dim` ≥ 4.5:1；`--accent` ≥ 4.5:1。三套主题都必须过（用工具实测，不靠目测）。

### 1.2 排版

正文用系统衬线栈，标题与 UI 用系统无衬线栈：

```css
--font-serif: "Songti SC", "SimSun", "Noto Serif CJK SC", "Source Han Serif SC", Georgia, serif;
--font-sans:  -apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif;
--font-mono:  "SF Mono", "JetBrains Mono", Menlo, Consolas, monospace;
```

| token | 默认 | 可调范围 |
| --- | --- | --- |
| `--font-size` | `20px` | 14–26px，步进 1px |
| `--line-height` | `1.9` | 1.5–2.4，步进 0.05 |
| `--letter-spacing` | `0.01em` | 0–0.05em |
| `--para-spacing` | `0.9em` | 0.4–1.6em |
| `--indent` | `2em` | 0 或 2em（中英混排时中文段首缩进） |
| `--measure` | `36em` | 26–48em（正文列宽） |
| `--word-spacing` | `0.02em` | — |

字号与行高的调整实时生效并持久化（`localStorage`）。

### 1.3 间距

`--sp-1: 4px` … `--sp-8: 64px`，4px 基数。常用：`--sp-2` 8px、`--sp-3` 12px、`--sp-4` 16px、`--sp-6` 24px、`--sp-8` 64px。

### 1.4 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 游标移动 | 180ms | `cubic-bezier(.4,0,.2,1)` |
| 主题切换 | 200ms | `ease` |
| 抽屉展开/收起 | 220ms | `cubic-bezier(.32,.72,0,1)` |
| 章节跳转滚动 | 300ms | `ease-out` |
| 逐词高亮点亮 | 90ms | `linear` |

遵循 `prefers-reduced-motion`：命中时全部动效降为 0ms，逐词高亮改为直接切换颜色。

## 2. 网页端布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏  48px                                                  │
├────────────┬─────────────────────────────────────────────────┤
│            │                                                 │
│  目录抽屉   │            正文列 (max-width: 36em)             │
│  280px     │            居中，垂直居中偏上                    │
│  可折叠     │                                                 │
│            │                                                 │
├────────────┴─────────────────────────────────────────────────┤
│ 听书条  56px（仅听书态出现，否则隐藏）                        │
└──────────────────────────────────────────────────────────────┘
```

- 顶栏：`left` 书架按钮 + 书名 / 章节名；`right` 字号 A- A+、主题切换、设置。
- 目录抽屉：TOC 树 + 搜索框。宽度 280px，折叠后正文列居中，占位不保留。
- 正文列：宽度由 `--measure` 控制；上下留白 ≥ 15vh。
- 听书条：贴底，播放/上一句/下一句/倍速/音色/关闭。

### 2.1 断点

| 宽度 | 行为 |
| --- | --- |
| ≥ 1024px | 三区并列，目录抽屉常驻可折叠 |
| 640–1023px | 目录抽屉改为覆盖层（overlay），正文列 `--measure` 减 4em |
| < 640px | 目录抽屉全屏覆盖；字号默认降到 17px；听书条收成一行图标 |

### 2.2 书架页

- 卡片网格：`repeat(auto-fill, minmax(160px, 1fr))`，卡片 = 封面 + 书名 + 作者 + 进度条。
- 无封面时用 `--text-faint` 底 + 居中的书名首字（字号 `2.5rem`）。
- 进度条：卡片底部 3px，填充色 `--accent`，表示全书百分比。
- 上传：右上角「导入 EPUB」按钮，拖拽整页亦可；拖拽悬停时页面出现 `--accent-soft` 遮罩与虚线框。
- 空态：一行居中文案 + 导入按钮 + 一句「只支持 EPUB」。

## 3. 阅读态交互

### 3.1 游标线

当前句的渲染结构：

```html
<p class="blk" data-sid="c12.b3.s0">
  <span class="sent" data-sid="c12.b3.s0">他把玫瑰留在原处。</span>
  <span class="sent" data-sid="c12.b3.s0.s1">风从远处来。</span>
</p>
```

- `.sent` 默认无样式（继承段落）。
- `.sent.is-current`：`background: var(--accent-soft)`；`box-shadow: inset 2px 0 0 var(--accent)` —— 即左侧 2px 琥珀竖线。
- 游标位置由**阅读带**决定：视口高度 30% 处的那一句是当前句。滚动停止 150ms 后重算。

### 3.2 听书态逐词高亮

听书时，句内每个词拆成 `<span class="w">`：

```html
<span class="sent is-current" data-sid="c12.b3.s0">
  <span class="w is-read">他</span><span class="w is-read">把</span><span class="w is-now">玫</span><span class="w">瑰</span>…
</span>
```

- `.w.is-now`：`background: var(--highlight)` —— 当前正在发音的词。
- `.w.is-read`：`background: var(--spoken)` —— 已读完的词（低对比，不抢眼）。
- 时间轴来自 `GET /audio/{sid}.words` 的 `words[]`，`start`/`end` 为**句内相对秒**。
- 播放时用 `requestAnimationFrame` 或 `audio.currentTime` 轮询（100ms）定位当前词。
- `granularity: "sentence"` 的回退引擎只做整句 `.is-current`，不做词级拆分。

### 3.3 自动跟随

- 播放中，当前句始终滚动到**阅读带**（视口 30% 处）。
- 用户手动滚动 → 暂停跟随，听书条上显示「跟随」按钮为未激活态。
- 跟随暂停时若已离开当前句超过 2 屏高，跟随按钮上显示一个小圆点提示。

### 3.4 点击定位

- 点击任一句 → 若在听书态，跳转到该句并从该句开始播放；若在阅读态，仅移动游标。
- 点击句内词（听书态）→ 跳到该词，词级粒度定位。

### 3.5 快捷键

| 键 | 动作 |
| --- | --- |
| `←` / `→` | 上/下一句（听书态：跳转并播放；阅读态：移动游标） |
| `Space` | 播放/暂停（仅听书态可用时；阅读态为翻页） |
| `↑` / `↓` | 滚动一行 |
| `PgUp` / `PgDn` | 翻页 |
| `Home` / `End` | 章节首/末 |
| `[` / `]` | 上/下一章 |
| `t` | 打开/关闭目录抽屉 |
| `/` | 聚焦搜索框 |
| `s` | 聚焦设置 |
| `+` / `-` | 字号 ±1px |
| `f` | 沉浸模式（隐藏顶栏与听书条，仅留正文与游标线） |
| `Esc` | 退出沉浸模式 / 关闭浮层 |

### 3.6 设置面板

一个抽屉，四个分区：**排版**（字号、行距、段距、缩进、列宽）、**主题**（纸白/羊皮/夜间/跟随系统）、**朗读**（性别、音色、倍速 0.75–2.0×、句间停顿 0–1.5s）、**数据**（分享当前位置、预生成音频、清除缓存、导出进度）。

- **性别**（女声/男声/不限）决定音色列表里出现哪些声音。音色按**书的语言**再挑一遍：中文书用中文，英文书用美式；语言不明（EPUB 写 `und`）时按服务端默认语言来。

## 4. 听书条

```
▶  ⏮ ⏭   ▁▂▃ 第三章 星辰            02:14 / 31:52   1.0×  🎙  ✕
```

- 左侧：播放/暂停、上一句、下一句。
- 中间：当前章名 + 迷你进度条（当前章内进度，橙色填充）。
- 右侧：总时间 / 已播时间（`mm:ss`）、倍速、**音色选择器**、关闭。
- 倍速是**弹出菜单**：0.75× / 1.0× / 1.25× / 1.5× / 1.75× / 2.0×，点按钮弹出，
  不再一轮轮地转。倍速通过 `audio.playbackRate` 实现；倍速只改播放速度，
  词边界是相对音频自身时间轴的，所以加速时光标照样贴着声音走。
  音色切换会清空该书音频缓存并重新预热。
- 音色选择器只列**常用音色**：中文（zh-CN）、美式（en-US）、英式（en-GB）各若干，取自 `GET /api/v1/meta` 的 `featured_voices`。
- 播放中提前把后面几句的音频与词边界**预取**回来（默认 3 句），避免断音；
  打开一章时后台预热开头几句，读到那儿时已经就绪。

## 6. 终端端：屏幕二 · 阅读

```
┌───────────────┬──────────────────────────────────────────┐
│ 目录 (30列)   │  第三章 星辰                              │
│ ▸ 第一章      │                                          │
│ ▸ 第二章      │  他把玫瑰留在原处。                       │
│ ▸ 第三章 ◀    │  风从远处来，带着一点凉意。                 │
│   第一节      │ ▎他把玫瑰留在原处。                       │
│ ▸ 第四章      │  风从远处来。                             │
├───────────────┴──────────────────────────────────────────┤
│ 第三章 星辰 · 12% · 句 128/312 · s 同步 · Space 听书  q 返回│
└──────────────────────────────────────────────────────────┘
```

- 左侧目录 30 列，章节可折叠；`Enter` 跳转。
- 右侧正文区，按 `--measure` 对应的终端列宽（建议 48–64 列）折行。
- **正文区不必铺满整屏**：默认只占中间一页（最多 26 行）并垂直居中，上下留白；
  按 `f` 才展开成整屏。这样一屏里能一眼看完目录、正文与状态栏，不会被文字淹没。
- 终端与网页读写同一份进度：终端停下 1.2 秒自动推送，网页每 5 秒拉取一次并跟随，因此两端始终在同一处接着读。
- 当前句：左侧 `▎` + 加粗 + `--accent` 色。
- 状态栏右侧实时显示 `句 n/N`，随滚动更新。

## 7. 终端端：屏幕三 · 听书

在阅读屏基础上叠加底部 3 行音频面板：

```
┌──────────────────────────────────────────────────────────┐
│ ▶ ⏮ ⏭  第三章 星辰 · 02:14/31:52 · 1.0× · zh-CN-Xiaoxiao   │
│ ▁▂▃▄▅▆▇█▇▆▅▄▃▂▁▂▃▄▅▆▇█▇▆▅▄▃▂▁  ▓▓▓▓▓░░░░░░░░░░░░░░░  │
│ 当前句：他把玫瑰留在原处。                                │
└──────────────────────────────────────────────────────────┘
```

- 逐词高亮与网页端同规则：当前词用 `--highlight` 底色，已读词用 `--spoken` 底色。
- 音频播放用系统命令：`afplay`（macOS）/ `ffplay`（Linux）/ `aplay`（Alpine）/ `mpv`（兜底）。
- 播放策略：逐句下载 MP3 到临时目录 → 交给播放器 → 播放结束后解析 `words` 时间戳推进高亮 → 预取下一句。
- 倍速通过 `ffmpeg -filter:a atempo=X` 或 `afplay -v` 近似实现（>=1.0 时直接调速参数）。

## 9. 无障碍

- 所有交互元素可键盘到达，焦点环用 `--accent`，2px，`outline-offset: 2px`。
- 当前句与当前词除颜色外另有形状/字重区分（当前句带竖线；当前词加粗），色觉障碍用户可辨。
- 听书条所有图标按钮有 `aria-label` 与 `title`。
- 正文容器 `role="document"`，章节切换时把焦点移到新章节首句并播报（`aria-live="polite"`）。
- 快捷键在 `?` 帮助面板中完整列出。

## 10. 可直接交给前端实现 agent 的嵌入 prompt

> 以下代码块可原样粘贴给负责 `web/` 与 `terminal/` 的实现 agent。

```
你在实现 Lector —— 一个 EPUB 阅读器 + 有声书播放器的界面层。

先完整读 /Users/thj/epub-reader/docs/UI.md 与 /Users/thj/epub-reader/docs/API.md，
再读 /Users/thj/epub-reader/AGENTS.md。三者冲突时以 docs/ 下的契约为准。

【必须实现的】
1. 网页端：书架页 + 阅读页 + 听书条 + 设置抽屉 + 目录抽屉 + 搜索。
2. 终端端：书架屏 + 阅读屏 + 听书屏。
3. 核心交互 —— 游标线（当前句左侧 2px 琥珀竖线 + 淡背景）与逐词高亮
```
